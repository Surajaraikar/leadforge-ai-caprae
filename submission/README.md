# LeadForge AI — assignment submission

LeadForge AI is a focused full-stack B2B lead-discovery and qualification platform created for the Caprae Capital Full Stack Developer assignment.

## What the application demonstrates

- Live business discovery by keyword and location using OpenStreetMap Nominatim
- Validation and filtering of irrelevant non-business results
- Deterministic duplicate removal
- Explainable lead scoring from 0 to 100
- SQLite persistence, server-side filtering, sorting, and 10-row pagination
- Full-list and selected-record CSV export
- Responsive desktop and mobile interfaces
- Honest missing-data handling and source attribution
